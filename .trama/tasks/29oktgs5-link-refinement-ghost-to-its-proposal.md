# Link refinement ghost to its Proposal

From the start of a refinement, the agent's announcement is bound to the Proposal being refined: it takes that Proposal's title, it is not a separate card, and its phase and latest note show on the Proposal's card in the Board. It is delivered when the Proposal is handed over and withdrawn like any Proposal announcement. The card's note line under its phase must show the latest note the agent declared for the refinement, and stay empty only when the agent declared none.
