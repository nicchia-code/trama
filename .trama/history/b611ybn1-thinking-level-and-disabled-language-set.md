# Thinking level and disabled language setting

Each model role and the Proposal model accept an optional thinking level, stored as <model>:<level>; Default means no suffix, so omp chooses. Settings and the wizard show a level select beside the model when omp declares levels for it, and the wizard summary shows the model and the level. The level travels with the model value to omp's model option, the Advisor overlay, the trama-implementer sub-agent, sequence runs and omp Chat, so Tasks with different levels fall into different sequence groups. The language setting is disabled for now: the configured language returns no language, so no instruction carries a language sentence. Implemented by Task vbcq0fwu. The --slow suffix and the advisor role are not yet checked on omp.
