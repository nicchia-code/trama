# Clear in the Done column

Clear in the Done column deletes the Tasks the column showed at the click, with no confirmation and no success notice. Before a Task is deleted, Trama writes its title, Proposal tag, arrival time in Done and references into every History entry that cites it; a Task whose copy fails is kept. Tasks named by an open Drift, as origin or correction, stay, with a kept badge. While a run started by Trama is in progress the request is refused, and a failure shows its reason in a notice at the top of the Board. Implemented by Task 7cj7ckql.
