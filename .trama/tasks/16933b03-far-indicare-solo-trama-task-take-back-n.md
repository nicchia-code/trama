# Far indicare solo trama task take-back nel rifiuto di una mossa del developer

Quando il developer prova a spostare un Task preso dall'agente, il rifiuto dice che l'agente ci sta lavorando e rimanda soltanto al comando `task take-back`: non cita più un bottone Take back sulla scheda, che non esiste più. Le mosse dell'agente restano sempre permesse.
