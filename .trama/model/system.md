# Trama

A tool for programming from a visual and textual Model of every state a software system can be in, plus the Requirements that say how it must be built. A developer reviews and decides on changes to the Model; a coding agent explores the Model, proposes changes, compares it with the code and implements the work it produces. Trama never calls a language model and never reads the developer's code: the agent does. Trama itself sends off the machine only the notification the developer turns on to be told, away from the computer, that the jobs of omp Chat have finished or wait for him (see Away notifications), and, with Manager mode on, the requests with which it reads through the GitHub command line the GitHub Project of the team (see Team). The PR Check, which also read the open pull requests, is hidden for now: no surface offers it and Trama reads no pull request (see the PR Check).

Il Modello e i Requisiti sono file del progetto. Le modifiche vengono proposte e approvate o rifiutate dal developer. Le differenze fra codice e Modello diventano Drift e il lavoro diventa Task, tutti sulla Board. Diagramma, Board e Requisiti permettono di esaminare il progetto e avviare design, scansioni, implementazione e import.

A developer who leads a team can turn on Manager mode and become its Manager: Trama then also keeps, in his editor, the people of the team, so that work can be planned for them as well as for the agent (see Team).

Trama is used from two surfaces that share one behaviour: a command line, which is how the agent reaches Trama, and the editor extension.

Trama also has a website, the documentation site on GitHub Pages, where a visitor reads the guide, illustrated with screenshots of the editor extension annotated with hand-drawn arrows and notes (see Website).
