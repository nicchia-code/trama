# Take New technical task off the Board

The Board no longer has a button to create a Technical Task by hand, and the editor no longer asks for a title for one. Technical Tasks still exist: the agent files them with the command line and tools, and fixing a Drift that only contradicts Requirements creates one. The Task machine's creation paths are the agent after a Scan or a Fix, and the developer's decision on a Drift.
