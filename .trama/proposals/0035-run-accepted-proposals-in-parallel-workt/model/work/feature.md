# Work

The work that comes out of comparing the Model with the code, shown on the Board. A Task is a unit of work for the agent that the developer can see and ask the agent to run, but not move on the Board. A Drift is a difference between code and Model, or between code and Requirements, that only the developer can decide on. While the agent is preparing a card, an announcement lets the Board show a ghost of it. I Task e i Drift nati in un worktree si vedono sulla Board del progetto aperto, e si decidono lì.
