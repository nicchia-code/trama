# Requirements, Specs e Get Started

Si fa dopo «Base React e shadcn».

- **Requirements.** È rifatta in React con i componenti di shadcn/ui: Aree, fragment e sezioni, selettore della Proposal disegnata e Markdown dal renderer comune.
- **Specs.** È rifatta in React allo stesso modo:
  - campi nell'ordine fisso, con le voci e il segno delle tecnologie scelte dall'agente;
  - errori in cima;
  - icona lucide `Package`.
- **Get Started.** È rifatta in React: avviso, Import from Code e Start from Scratch come `Button`, entrambi non premibili mentre una scelta è in corso.
- **Cosa resta uguale.** Testi, ordine e messaggi all'host sono quelli dei Requisiti.
- **Codice vecchio.** Il codice di disegno DOM delle tre schede sparisce.
- **Test.** I test di `specs-view` e `specs-icons` passano a Testing Library.
