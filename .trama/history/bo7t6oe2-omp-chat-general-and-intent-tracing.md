# omp Chat General and Intent Tracing

General is a conversation of omp Chat kept by the host: its process, queue, Clear General and Install omp. A message that did not start returns to the field. Intent Tracing is set per omp Chat conversation, with the setting trama.ompChatIntentTracing, and the terminal title keeps its plain form when it is off.
