# Website

Trama's documentation site, published on GitHub Pages from this repository. It has two parts: a landing page that tells the loop of Trama with animations as the visitor scrolls, and a guide that explains how to use Trama.

The guide is a traditional one: the pages that teach how to do something go step by step, and every step shows a screenshot of the real VS Code window with the extension, annotated with arrows, circles and short notes that look drawn by hand, in the style of Excalidraw. The screenshots exist in a light and a dark version and follow the theme the visitor chose for the site; the visitor can open any of them enlarged.

The site is static: it never runs Trama and nothing the visitor does leaves the browser.
