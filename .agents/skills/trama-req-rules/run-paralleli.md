# Requirements: Regole di business, Regole dei Run per modello in parallelo e della stima di Run all

Usa quando lavori sulla sequenza per modello di Run all lanciata in parallelo, sulla divisione del limite dei sotto-agenti fra i suoi Run e sulla stima del tempo che manca a un Run all.

## drift-resolution/Running tasks

- Sequenza in parallelo, con `trama.parallelExecution` acceso al lancio di `Run all` e più gruppi di modello (`rules#agent-launching`): l'host divide il limite dei sotto-agenti N (`rules#agent-terminal`) fra i gruppi in proporzione ai loro Task eseguibili al lancio, almeno 1 a gruppo, con la somma che non supera N: a ogni gruppo la parte intera di N per i suoi Task diviso il totale, almeno 1, poi i posti avanzati uno ciascuno ai gruppi con il resto più grande, a parità al gruppo con il Task più vecchio. Le parti non si ricalcolano quando un Run finisce.
- Ogni Run porta la sua parte al posto di N nella frase del limite e nel `max` di `trama task list`; il resto della sua istruzione, il suo modello e il nome del suo terminale sono quelli della sequenza di oggi.
- Partono insieme, nell'ordine dei gruppi, tanti Run quanti ne stanno in N con almeno un posto ciascuno. Con più gruppi che posti, i gruppi rimasti partono uno alla volta, ciascuno con un posto, alla fine normale di un Run già partito.
- Una fine anomala di un Run della sequenza in parallelo non ferma i Run già partiti, che finiscono il loro lavoro: ferma solo i gruppi che non sono ancora partiti.
- Le prenotazioni dei file (`rules#prenotazione-file`) valgono fra i Run della sequenza come fra due Run qualsiasi.
- Stima del tempo che manca a un Run all: la calcola Trama, senza l'agente e senza nessun modello, dalle registrazioni dei tempi (`rules#work`), dai Task e dai posti. C'è solo per un `Run all` lanciato dalla finestra, sequenza per modello compresa, dal lancio alla fine del suo ultimo Run o al suo arresto; il Run di un solo Task non ha stima.
- Records of a Run: the timing records of its terminal or of its conversation made from the launch of the Run all on. Earlier records of a reused terminal or conversation are not the Run's: they do not make it started, do not make its plan, do not make a Task its own and do not end one.
- Task di un Run: i Task eseguibili in To do del suo ambito (per un Run di una sequenza per modello, quelli del suo gruppo) e i Task In progress presi dal suo terminale o dalla sua conversazione. Un Task la cui fine (`done`, `unchanged` o `drift`) è registrata dal Run non conta più. I Task bloccati non contano.
- Peso di un Task: 1 minuto per un Task di correzione (un Task con un Drift); per ogni altro Task la media delle durate dei Task finiti con esito `done` nelle registrazioni che Trama tiene, contando solo le durate sopra i 30 secondi e solo quelle dei lavori diversi dal Run all in corso. Con meno di 10 durate così il peso è 9 minuti. Un Task In progress pesa il suo peso meno il tempo passato da quando il Run lo ha preso, mai meno di 1 minuto.
- Piano di un Run con Parallel Execution: ogni scelta `order` o `conflict` che il Run ha registrato fa aspettare il primo Task della scelta agli altri Task della scelta che sono Task del Run; una scelta che chiuderebbe un ciclo di attese non conta. Il tempo dei Task è il più grande fra la catena di attese più lunga (la somma dei pesi lungo la catena) e la somma di tutti i pesi divisa per i posti del Run (N o la sua parte). Senza Parallel Execution il tempo dei Task è la somma dei pesi.
- Stima di un Run partito: 0,5 minuti di avvio finché il Run non ha preso nessun Task, più il tempo dei Task, più 2,5 minuti di coda (verifica finale, History, passaggi). Quando nessun Task del Run resta, la stima è soltanto la coda che resta: 2,5 minuti meno il tempo passato dall'ultima fine di Task registrata dal Run, mai meno di 0,5 minuti. Un Run non ancora partito vale avvio, più la somma dei pesi dei suoi Task, più coda.
- Stima di una sequenza per modello: con i Run uno dopo l'altro, la somma delle stime dei Run partiti e non partiti; con i Run insieme, la più lunga fra le stime dei Run, dove un Run che aspetta un posto vale la stima più breve fra i Run partiti più la propria.
- Quando c'è la stima: con Parallel Execution dalla prima registrazione del piano di un Run della sequenza (la prima scelta, il primo Task preso o la prima richiesta dei posti, `queue`); senza Parallel Execution dal lancio. Prima di allora la stima è in calcolo.
- Forchetta: il limite basso è la stima per 0,7, il limite alto la stima per 1,5. Sotto i 60 minuti del limite alto i due limiti si arrotondano al minuto, almeno 1; da 60 minuti in su si scrivono in ore arrotondate alla mezz'ora, almeno mezz'ora.
- La stima si rifà a ogni nuova registrazione dei tempi dei terminali o delle conversazioni del Run all e una volta al minuto mentre il Run all è in corso.
- Reference of a Run all: the time from the launch beyond which the Run all is longer than expected. There is none until a Run of the Run all has taken its first Task; at that moment it is the time passed since the launch plus the high limit of the estimate made then. It is made again, in the same way, at every change of the plan: a new `order` or `conflict` choice recorded by a Run of the Run all, or a Task that becomes a Task of one of its Runs without having been one before in this Run all (for example a fix Task born during the run, or a Task no longer blocked). The mere passing of time, the end of a Task, a Task leaving the Runs and a recomputed estimate without a change of the plan leave it as it is.
- Longer than expected (più lungo del previsto): while the time passed since the launch of the Run all exceeds its current reference, the Run all is longer than expected. When a change of the plan moves the reference beyond the time passed, it no longer is. Without a reference it never is.
- Avanzamento di un Run all: la parte fatta è il tempo passato dal lancio diviso per la somma del tempo passato e della stima rifatta (la stima centrale, non un limite della forchetta). Non supera mai 0,95 prima della fine del Run all, e non torna mai indietro: quando la stima rifatta cresce, l'avanzamento resta il più alto già raggiunto finché il nuovo calcolo non lo supera. Più lungo del previsto, l'avanzamento vale 0,95; that value does not count as reached: when the Run all is no longer longer than expected, the progress is computed again as above from the highest value reached outside that state, so it can go back below 0.95. Mentre la stima è in calcolo non c'è avanzamento. L'avanzamento si rifà insieme alla stima, e come lei non si scrive da nessuna parte. In percentuale si arrotonda all'intero.
- La stima non si scrive da nessuna parte: non va sotto `.trama/`, non cambia le registrazioni dei tempi né `trama timing list`, e alla fine del Run all si dimentica.
