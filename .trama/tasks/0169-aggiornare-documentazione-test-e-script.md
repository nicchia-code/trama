# Aggiornare documentazione, test e script di accettazione per le richieste già su disco

La documentazione descrive la richiesta scritta com'è ora: il file nasce vuoto con Design…, con il nome di data e ora, è salvato da Trama mentre il developer scrive, chiudere la scheda la invia (o la cancella se vuota), Send to agent chiude la scheda, una richiesta si invia una sola volta e Trama ricorda le inviate dopo un riavvio.
