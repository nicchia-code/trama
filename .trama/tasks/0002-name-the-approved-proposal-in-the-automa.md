# Name the approved Proposal in the automatic Scan and link its Tasks

After an ordinary Proposal is approved, the scan that starts automatically is told which Proposal it comes from and asked to link every Task it files to it. A Scan the developer starts by hand names no Proposal, so its Tasks belong to no design. The scan skill given to the agent explains how to use the link when it receives a Proposal, and how to file Tasks without it otherwise. Depends on the Task link.
