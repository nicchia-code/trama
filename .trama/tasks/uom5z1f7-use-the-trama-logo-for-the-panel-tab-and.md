# Use the Trama logo for the panel tab and the extension icon

Il logo di Trama, le barre intrecciate, compare in un solo colore sull'icona della barra e sulla scheda del pannello: scuro nei temi chiari, chiaro nei temi scuri. L'estensione nell'elenco delle estensioni mostra il logo nero su fondo bianco. Le icone stanno nel pacchetto dell'estensione e finiscono nel file .vsix.
