# Agent questions

How the coding agent asks the developer to choose during design and import. Al posto dell'interfaccia di domande di ciascun agente, Trama presenta un round di domande in un overlay sopra il proprio pannello nell'editor, una domanda alla volta, con scelta singola o multipla, una raccomandazione, un contesto più lungo facoltativo per ogni domanda, dettagli più lunghi facoltativi per ogni opzione e uno spazio per la risposta libera sempre a portata di mano. Un indice permette di andare a qualunque domanda, e un riepilogo finale mostra tutte le risposte prima che il developer invii il round all'agente. Il developer può ridurre l'overlay per guardare il Modello mentre risponde.

Every agent, whether it runs in an editor's chat or in a terminal, uses the same behaviour. When the editor is not available for the project before the round is requested, the agent asks through its own question interface, or in conversation when it has none. If the editor is lost after accepting the round, the round is interrupted and the agent stops the workflow that was waiting for those decisions; it does not fall back to another question interface. Trama displays questions and returns the developer's answers; it does not call a model or choose an answer for the developer.

Only one round is presented at a time in an editor window. Others wait in order. A skipped question is explicitly reported to the agent, which uses its recommendation and lists that decision for the developer to verify. Stopping the agent's wait abandons its round rather than treating it as answered. Chiudere l'overlay equivale a saltare tutte le domande ancora senza risposta, dopo una conferma; chiudere il pannello invece non tocca il round, che resta in attesa.

Losing the editor interrupts every active or queued round assigned to that window and discards all answers of those incomplete rounds. No partial answers or automatic recommendations are returned, and the rounds are not moved to another window or resumed when the editor returns. Rounds in other windows are unaffected.

Quando il round è finito, l'agente in design non chiede al developer di confermare un riepilogo prima di aprire la Proposal: la apre e la scrive direttamente, e il developer la giudica come ogni Proposal.
