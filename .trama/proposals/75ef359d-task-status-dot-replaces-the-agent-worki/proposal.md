# Task status dot replaces the agent working badge; drop the in-writing card

The 'agent working' badge on Tasks is replaced by the status dot, which now appears on every Task card (left of its ID) and on each Task row of a design card. The dot pulses only while the agent is actually working on the Task (taken by the agent); otherwise it is told apart by colour (To do, In progress, Done). The 'in writing' Proposal card on the Board is removed for now; a more generic card will come later. Until then a draft is discarded only with the command line. Decisions confirmed with the developer.
