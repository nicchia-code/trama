# Teach the skills that file Drifts to write fix options

The skills trama-scan, trama-fix, trama-implement and trama-import tell the agent to give every Drift from two to five fix options, the recommended one first, each a different way to reach what should happen and not a step of one plan, written in terms of behaviour with about 60 words and no headings or tables, and to pass them with --option and --option-text (or the options list of the tool). The skills that attach a Proposal to a Drift (trama-design) file it the same way. The skills still say that code locations go only in Where in the code.
