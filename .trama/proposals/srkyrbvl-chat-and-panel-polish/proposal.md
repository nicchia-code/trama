# Chat and panel polish

Thirteen small changes from the developer's written request, across omp Chat, Settings, the side menu, the Board and the launch instruction, plus one bug.

## Decisions
- omp Chat: a two-option switch `Steer | Queue` next to `Send` in every conversation, General included; one choice shared by all conversations and remembered across reloads.
- Queue uses omp's own follow-up queue: the message reaches the agent when it would end its turn; it shows a `Queued` mark until delivered.
- In Steer mode a message sent while a permission request waits is queued as in Queue mode; the request stays open.
- Thinking level: one per model role (analysis, scan, execution), stored as omp's `:level` suffix of the model value; a small select (`Default` plus the model's levels) beside the model field in Settings, in the setup wizard's Models step and in the Board's Proposal model dialog. Shown only when omp declares levels for the chosen model; a model change to one that lacks the saved level goes back to `Default`.
- Language field: greyed out in Settings with a note that agents write in English for now; any saved value is ignored, so no language sentence is added.
- The Trama logo leaves the status bar; its icon font, generation script and dev dependency are deleted. The ghosts' status bar item stays.
- Tooltips: removed from the whole side menu (every mode, icon-only too) and from the items of dropdown action buttons on cards and dialogs; accessible names stay.
- Disabled Scan System: a muted line under the button in wide mode says why; hidden in icon-only mode.
- Icon-only mode of the side menu below about 56 px (icon plus padding), so in the side bars the menu always shows its texts.
- Proposal tags hidden on every Board card (Backlog rows, Active, Done); reference chips stay; Task cards in Active and Done keep a thin left edge in the tag's colour; the Task details window shows the tag behind a `Show tags` toggle, closed every time it opens.
- General gets a Trama instruction (Trama's assistant chat in the editor, helps with the project and with Trama, uses Trama's skills and the `trama` command line, never edits `.trama/` by hand), added to omp's system prompt at launch; if omp's ACP mode does not accept it, prepended to the developer's first message instead (developer's fallback).
- Ask more, Ask question and General never send Trama's instruction before the developer writes: the chat opens empty with the focus in the field and a placeholder naming the subject (`Ask about T3 – Title…`); the instruction is joined to the first message, marked as instructions; the transcript shows only the developer's message; the ghost appears only after the first message; closing an empty chat leaves no trace. With omp Chat off, Ask more in the terminal still sends at once.
- Markdown tables render everywhere through the shared renderer: inline Markdown in cells and column alignment; cells wrap up to a maximum width, beyond that the table scrolls sideways inside its own box, also after a resize.
- omp Chat icons: real logos from simple-icons (CC0, only the icons used) for code cells (`[py]`, `[js]`, tag removed) and for file rows by extension (common set: Python, JavaScript, TypeScript, JSON, Markdown, HTML, CSS, YAML, Rust, Go, Java, Swift, Kotlin, C, C++, C#, Ruby, PHP, shell scripts); the logo replaces the kind icon; shell rows keep the terminal icon and lose the `$`.
- Auto exit on: one sentence in the launch instruction tells the agent to end with one short line at most, no summary; the skills stay unchanged; the sentence follows the setting at launch, closing follows it at the end.
- Bug: `Clear` in Done sends `clearDone`, which the host refused as unknown; it must reach the controller.

## Assumptions
- The Steer/Queue switch starts at Steer the first time.
- Task rows inside Proposal cards in Backlog get no coloured edge: the card already groups them.
- The tag tooltip in the details window stays: only the side menu and dropdown items lose tooltips.
- The auto-exit sentence sits after the ask-the-developer sentence and before the language sentence, in every hooked job (terminal and omp Chat); Ask more and General never close on idle and do not get it.
- The developer reported that steering seems to do nothing: the Task checks that a steered message really reaches omp.
- Messages still queued are dropped by Stop, by closing the conversation and by closing the window; a queue already handed to omp follows omp.
- An Ask more conversation still empty is not saved and does not come back after a reload; its `Send` stays disabled until omp's session is open, so a failed start (which falls back to the terminal, sending at once) loses nothing written.
- Disabled items of dropdown menus (`Unify Drifts`) show their reasons as a muted line under the label instead of a tooltip; the dropdown arrows keep their own tooltips.
- Table cells wrap within about 320 px (20rem); columns narrow down to their longest word, then the table scrolls inside its box.
- Language and file logos are drawn in the row's text colour at the size of the kind icon they replace; a type that simple-icons lacks keeps the generic icon.
- Ask more and General's fallback join instruction and message with the headers `Instructions from Trama (not written by the developer):` and `Developer's message:`.
- The thinking level travels with the model everywhere (`--model`, `--slow`, the advisor, omp Chat); the Task verifies omp accepts the `:level` suffix in each place.
- Fragments that went over 12 KB are split without changing section text: `ui#General` moves to the new fragment `ui/general`, `ui#omp-chat-conversation` to `ui/omp-chat-conversation`, `tech#omp-chat-conversation` to `tech/omp-chat-conversation`, `ui#panel/Specs` to `ui/specs`; the new text in `rules/agent-terminal`, `rules/models` and `tech/agent-terminal` is kept short, with the details in the Tasks.
