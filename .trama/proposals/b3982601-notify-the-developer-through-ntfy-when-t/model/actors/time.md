# Time

The passing of time, which no one in the System controls.

## Events

### QUIET_PERIOD_ELAPSED
Fifteen minutes passed since the agent last did anything about a card it announced: announcing a card, working on its Draft or filing a card. The period does not run while a question round is open.

### NOTICE_DELAY_ELAPSED
Passarono dieci secondi da quando è nato un avviso sulla fermata dell'agente, senza che il developer abbia risposto.

### RETRY_DELAY_ELAPSED
Passarono dieci secondi da quando l'invio di un avviso è fallito la prima volta.
