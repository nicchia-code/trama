# Scan every Feature when an approved Proposal changes an Area's description

After an ordinary Proposal is approved, a change to an Area's description affects every Feature, like a change to its introductory text or General section does. Today only the introduction and the General section are compared, so a Proposal that changes only a description starts no scan.
