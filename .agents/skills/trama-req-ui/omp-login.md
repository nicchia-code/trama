# Requirements: Interfaccia, Login dei fornitori di omp

Usa quando costruisci o cambi la sezione Providers del login ai fornitori di omp, il suo terminale o la chiave API di Cursor.

## developer.LOG_IN_PROVIDER

- La sezione `Providers` sta, nel gruppo `omp` della scheda Settings e nel passo `omp` del wizard, subito sotto il riquadro dello stato di omp e prima delle impostazioni; è lo stesso componente nei due posti, con gli stessi testi. C'è solo quando `rules#developer.LOG_IN_PROVIDER` dice; quando manca non lascia spazio vuoto.
- In cima alla sezione il sottotitolo «Providers», come intestazione del livello successivo a quello del gruppo (nella scheda) o del passo (nel wizard); sotto, in testo secondario, «Log in to the model providers you use with omp, or log out of them.».
- Sotto, un elenco con nome accessibile «Providers», una riga per fornitore nell'ordine di `rules#developer.LOG_IN_PROVIDER`, separate da un bordo sottile. Ogni riga ha a sinistra il nome breve in grassetto e, sotto, l'abbonamento in testo secondario; poi lo stato; a destra il pulsante. Nei pannelli più stretti di circa 480 px il pulsante va sotto il nome e lo stato, allineato a sinistra. Nulla si sovrappone o esce dalla colonna, a qualunque larghezza da circa 300 px e in entrambi i temi; i testi lunghi vanno a capo.
- Stato, sempre anche a parole e non solo con il colore: collegato, l'icona lucide `CircleCheck` nel colore di successo e «Connected»; non collegato, «Not connected» in testo secondario, senza icona; sconosciuto, nessuno stato e nessuno spazio vuoto. Un cambio di stato non sposta il fuoco e non cambia l'altezza delle altre righe.
- Pulsante: `Button` di shadcn/ui nella variante `outline`, piccolo, con l'icona lucide `LogIn` a sinistra del testo: «Log in» per un fornitore non collegato o di stato sconosciuto, «Log in again» per uno collegato. Tooltip «Open a terminal that logs omp in to <nome breve>»; nome accessibile «Log in to <nome breve>» o «Log in again to <nome breve>».
- Google Gemini CLI e Google Antigravity hanno in più un tooltip che li distingue, al passaggio del puntatore sul nome e sul pulsante e al fuoco del pulsante, collegato al pulsante con `aria-describedby`: Google Gemini CLI «Gemini models through Google Cloud Code Assist, the Gemini CLI login.»; Google Antigravity «Gemini, Claude and GPT-OSS models through Google's Antigravity login.». Sul pulsante il tooltip mostra questa frase sopra quella del pulsante.
- Nessun tooltip compare da solo, come in `ui#setup-wizard`. Tutto si raggiunge e si usa da tastiera.
- Il terminale di login si chiama «Log in to <nome breve>» (per esempio «Log in to Anthropic»), si apre nell'area dei terminali qualunque sia `trama.terminalLocation`, diventa il terminale visibile con il cursore dentro e non ha ghost. Nessun avviso dell'editor alla fine del login.
- Tutti i testi sono in inglese e non seguono `trama.language`.

## developer.LOG_OUT_PROVIDER

- `Log out`: `Button` of shadcn/ui in the `ghost` variant, small, with the lucide icon `LogOut` left of the text «Log out», right after «Log in again» in the row's button group (on the Cursor row after «Log in again» and before the API key buttons). Tooltip «Make omp forget its accounts of <nome breve>»; accessible name «Log out of <nome breve>». In panels narrower than about 480 px it goes below the name and the state with the other buttons of the row, wrapping without leaving the column. No tooltip shows by itself.
- Its appearing and disappearing, when the row becomes Connected or not, does not change the height of the other rows nor move the focus, except as below.
- Confirmation: a modal editor warning (`showWarningMessage` with `modal: true`), message «Log out of <nome breve>?», detail «omp forgets every account of <nome breve> it stored. Credentials in environment variables, `.env` files or `models.yml` stay.», and the button «Log out»; the editor adds its own Cancel.
- While it runs: the `LogOut` icon becomes the lucide `Loader` spinning (still with `prefers-reduced-motion`), the text stays «Log out», and the row's buttons are disabled and marked so for assistive technologies; the row has `aria-busy="true"`. When the check ends the focus goes back to «Log in» or «Log in again» of the same row.
- Failure: editor error message «Trama: could not log out of <nome breve>: <reason>.».
- Still connected: editor information message «Trama: <nome breve> is still connected through another credential (environment variable, `.env` file or `models.yml`). Remove it there to disconnect.»; on the Cursor row with a saved Cursor API key: «Trama: Cursor is still connected through the Cursor API key saved in Trama or another credential. Remove them to disconnect.». No message confirms a logout that disconnected the provider: the row says «Not connected».
- All texts are in English and do not follow `trama.language`.

## developer.SET_CURSOR_API_KEY

- Riga Cursor con una chiave salvata: sotto l'abbonamento («Cursor subscription or API key»), una riga in testo secondario «API key saved», senza icona e senza nessuna parte della chiave. Senza chiave salvata la riga non c'è e non lascia spazio vuoto. Lo stato «Connected» / «Not connected» resta quello di `ui#developer.LOG_IN_PROVIDER`.
- Pulsanti della riga Cursor, a destra, nello stesso gruppo di «Log in» e dopo di lui, con lo spazio fra pulsanti della sezione: il pulsante della chiave, `Button` di shadcn/ui nella variante `outline`, piccolo, con l'icona lucide `KeyRound` a sinistra del testo, «Set API key» o «Change API key»; con una chiave salvata, dopo di lui, «Remove API key», `Button` nella variante `ghost`, piccolo, con l'icona lucide `Trash2`. Nei pannelli più stretti di circa 480 px il gruppo va sotto il nome e lo stato come il pulsante delle altre righe, e i pulsanti vanno a capo fra loro senza uscire dalla colonna, a qualunque larghezza da circa 300 px e in entrambi i temi.
- Tooltip e nomi accessibili: il pulsante della chiave ha tooltip «Save a Cursor API key that Trama passes to omp» e nome accessibile «Set Cursor API key» o «Change Cursor API key»; «Remove API key» ha tooltip «Remove the Cursor API key saved in Trama» e nome accessibile «Remove Cursor API key». Nessun tooltip compare da solo, come nel resto della sezione.
- Casella della chiave: la casella di input in cima alla finestra dell'editor, con titolo «Cursor API key», testo «Paste a user API key from the Cursor dashboard. Trama keeps it in the editor's secret storage.», carattere mascherato e nessun segnaposto con la chiave; con un testo vuoto o di soli spazi mostra sotto il campo «Enter a Cursor API key.». La casella non si chiude quando il fuoco passa altrove, così il developer può copiare la chiave da un'altra finestra.
- Salvata o tolta la chiave, il fuoco torna al pannello sul pulsante della chiave della riga Cursor; nessun avviso dell'editor conferma il salvataggio o la rimozione. Comparire o sparire di «API key saved» e di «Remove API key» non cambia l'altezza delle altre righe.
- Errori del portachiavi: un messaggio di errore dell'editor con i testi di `rules#developer.SET_CURSOR_API_KEY` e `rules#developer.REMOVE_CURSOR_API_KEY`.
- Tutti i testi sono in inglese e non seguono `trama.language`.
