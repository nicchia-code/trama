# Rename Jasper to Trama

The product, the CLI binary, the project folder (`.trama/`), the skills, the extension and its settings are all called Trama. The working name Jasper collided with the `jasper` JPEG-2000 tool that Arch, Debian and other distributions install as `/usr/bin/jasper`, so agents and developers could run the wrong program; renaming only the binary would have left two names for one product. `trama` was free as a command, as a distribution package and on npm when the rename was made, and there were no users or projects to migrate.
