# Requirements: Regole di business, Regole dei round di domande

Generated by Trama from `.trama/requirements/rules/questions-notices.md`. Do not edit this file: change the Requirements through a Trama Proposal (or ask the developer).

These are the developer's Requirements for how the System is built. Follow them when you write code. The Model (`.trama/model/`) says what the System does; when a Requirement and the Model disagree, stop and tell the developer.
A section titled with a Model reference (such as `order/Paid`) applies to that element and to everything inside it.

## question-round

- Validate the complete request before queueing or presenting anything: at least one question, unique non-empty question IDs, non-empty question text, at least two options per question, non-empty option labels, descriptions, a boolean `multi` and an integer recommendation index within the options. `context` e `details`, quando presenti, devono essere stringhe non vuote dopo aver tolto gli spazi. Refuse an invalid round with an error rather than asking a partial round.
- Una domanda si conferma con almeno un'opzione o un testo libero non vuoto, o entrambi, sia a scelta singola sia multipla. A single-choice answer cannot include multiple options. Whitespace-only free text is empty and is not delivered. Saltare una domanda è il pulsante Skip, senza conferma, ed è diverso dal confermare senza scelte (che non è possibile).
- Le risposte confermate e quello che è scelto o scritto senza conferma restano attraverso Back, i salti dall'indice, la riduzione a barra e la chiusura del pannello. Confermare una risposta rivista sostituisce la precedente, senza duplicarla. Quello che è sulla domanda senza conferma non arriva mai all'agente. Annullare la conferma di Skip all non cambia nulla.
- Skip salta solo la domanda corrente. Skip all, confermato, salta tutte le domande senza una risposta confermata, prima o dopo la corrente, e tiene tutte quelle confermate; consegna subito il round senza riepilogo. The agent applies its recommendation for each skipped question and explicitly lists those decisions for the developer to verify.
- Send to agent consegna il round solo quando ogni domanda è risposta o saltata; l'host rifiuta un invio con domande mancanti anche se arrivasse dal pannello.
- Dopo che l'agente ha smesso di aspettare, o il round è finito, `Reopen` sulla notifica di domande in attesa apre solo il pannello e non mostra nessun round.
- Present at most one round per editor window. Admit concurrent rounds in FIFO order, present each as a whole and do not interleave their questions. Cancelling a queued round removes only that round; finishing or abandoning the active round opens the oldest remaining one.
- Route an agent launched in a Trama terminal to its launching window. Otherwise use the most recently focused window with that same project open. Never show a project's questions in a window for a different project.
- There is no Trama response timeout. When the caller stops waiting, remove its queued round or close its active controls and discard its answers. A stopped caller must not leave an orphaned menu or block the queue.
- `trama-design` and `trama-import` use `trama ask` for every question round. Only if the editor is unavailable before admission do they fall back to the agent's own question tool, or a numbered round in conversation when no question tool exists. An input error is corrected, not treated as editor unavailability; a deliberate skip is not re-asked through the fallback.
- Le skill tengono `question` breve, una frase che si legge da sola; mettono lo sfondo della decisione in `context`, il compromesso in poche parole in `description` e la spiegazione lunga, quando serve, in `details`.
- Finito l'ultimo round dell'intervista, `trama-design` apre la Proposal e la scrive senza chiedere al developer di confermare un riepilogo; mette nel corpo della Proposal il riassunto delle decisioni. Il passo di conferma della comprensione condivisa sparisce dalla skill.
- Losing the editor after admission interrupts every active or queued round assigned to that window and discards all answers of those incomplete rounds. The agent stops the workflow awaiting those decisions; it must not continue using partial answers, apply recommendations, fall back to another question interface, automatically retry, reroute to another window or resume the round when the editor returns. Rounds assigned to other windows are unaffected.
