# Teach the skills that file or rework Drifts to write both sides and to replace a stale Proposal (technical)

The skills for scanning, fixing, implementing and importing file each Drift with both its What happens and its What should happen text, and say so in their steps and tool tables. The design skill knows how to rework the stale Proposal of a Drift without asking questions and attach the new one in place of the old with the new command, and lists the new tool. The skills installed in the project are refreshed.
