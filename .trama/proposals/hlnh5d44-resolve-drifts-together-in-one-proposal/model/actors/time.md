# Time

The passing of time, which no one in the System controls.

## Events

### QUIET_PERIOD_ELAPSED
Fifteen minutes passed since the agent last did anything about a card it announced: announcing a card, working on its Draft or filing a card. The period does not run while a question round is open. Per un Run o una risoluzione dei Drift (vedi Drift resolution) conta ogni comando di Trama con cui l'agente cambia qualcosa: annunci, Draft e decisioni sui Drift, schede archiviate, Task spostati.
