# Carry the chosen option and note from the panel when the developer fixes the code

When the developer keeps what should happen in the Diagram or the Board, the editor receives the number of the selected option and the note along with the decision, and fixes the code with them. The decision to keep what happens (accepting the Proposal or dismissing) carries neither. A refusal, for instance an option that no longer exists after the Drift changed, is shown to the developer in the editor and the Drift stays Open.
