# Let the developer confirm an empty reason when rejecting a Proposal in the editor

The Reject button asks for feedback in an input that says the feedback is optional and accepts an empty or blank answer, which rejects the Proposal with no feedback. Cancelling the input still rejects nothing. The wording of the Reject button's tooltip does not say that feedback is required.
