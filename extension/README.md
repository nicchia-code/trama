# Trama

Trama keeps a map of your app next to your code and raises a Drift when the two stop agreeing. See the project README for how it works.

## Settings

Trama's settings are changed from the VS Code settings, or from the **Settings** tab of the Trama panel. The tab has four groups: **Agent**, **Models**, **Project** and **Features**. It always writes to the user settings, never to the workspace.
