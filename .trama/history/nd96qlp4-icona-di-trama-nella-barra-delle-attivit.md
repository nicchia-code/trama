# Icona di Trama nella barra delle attività

In ogni finestra con almeno una cartella aperta compare nella barra delle attività l'icona di Trama, con una vista `Trama` che mostra una frase e il pulsante Open Trama, identico al comando Open Trama. Il pulsante nella barra di stato mostra solo il logo, tramite il font di icone `trama-logo` rigenerabile con `scripts/icon-font.ts`. L'icona per aprire Trama nella barra del titolo dell'editor è stata tolta.
