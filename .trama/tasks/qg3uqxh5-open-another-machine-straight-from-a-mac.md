# Open another Machine straight from a Machine's level

Oggi, dal livello di una Machine, il developer raggiunge un'altra Machine solo risalendo alla Feature con il breadcrumb e aprendo quella Machine da lì. Il Modello prevede invece che dal Machine level si apra direttamente un'altra Machine. Fatto quando: dal livello di una Machine il developer apre il livello di un'altra Machine con un solo passaggio, e il livello mostrato e la selezione sono quelli descritti dal Modello.
