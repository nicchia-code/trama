# Remove the in-writing Proposal card from the Board

The Board no longer shows a card, nor a band above the columns, for a Proposal the agent is still writing, and so offers no Discard button there. A draft is discarded only with the command line. Drafts still do not count as awaiting a decision, and the textual board and proposal list keep listing them as 'In writing' and '(draft)'. The manual acceptance steps that describe the draft card and its Discard button no longer apply.
