# Requirements: Tecnologia e vincoli, Tecnologia degli annunci

Generated by Trama from `.trama/requirements/tech/announcements.md`. Do not edit this file: change the Requirements through a Trama Proposal (or ask the developer).

These are the developer's Requirements for how the System is built. Follow them when you write code. The Model (`.trama/model/`) says what the System does; when a Requirement and the Model disagree, stop and tell the developer.
A section titled with a Model reference (such as `order/Paid`) applies to that element and to everything inside it.

## announcement

- `trama announce <proposal|task|drift> "<title>"` prints the new announcement's ID. It is not developer-only: the agent runs it.
- `trama announce check "<title>" --phase <verifying|scanning>` annuncia un controllo e ne stampa l'ID; come ogni `trama announce`, copia `terminal` o `chat`. `--phase` è obbligatorio per `check` e rifiutato per gli altri tipi. `trama announce phase <id> scanning` passa un controllo in Verifying a Scanning; `trama announce done <id>` lo consegna e cancella il file. Nessuno dei tre è riservato al developer. Un ID sconosciuto, già consegnato o ritirato, o che non è un controllo, non è un errore: l'uscita dice che il controllo non è stato trovato e il comando finisce con successo, così l'agente non si ferma. `trama announce phase` su un controllo già in Scanning non cambia nulla e lo dice.
- `trama proposal new`, `trama task new` and `trama drift new` take an optional announcement ID (`--announcement <id>`). The command that hands a Proposal over needs no ID, since the Draft is already bound.
- Every terminal Trama starts for an agent gets the environment variable `TRAMA_TERMINAL`, an ID of six random lowercase letters and digits that stays with the terminal for as long as it exists, including when it is reused. `trama announce`, and a `trama proposal new` that makes an announcement of its own, copy that variable into the announcement's `terminal`; without the variable the announcement has none. The announcement Trama makes for a design request gets the ID of the terminal it types into.
- La riga di comando scrive e cancella i file degli annunci; l’estensione li cancella quando li ritira. L’estensione può inoltre aggiornare esclusivamente l’H1 di un annuncio Writing già associato a una Draft, affinché coincida con il titolo corrente della Draft anche dopo una modifica diretta. La Snapshot legge gli annunci come gli altri file del progetto e il pannello si aggiorna quando cambiano.
- La deroga riguarda soltanto il titolo: la sincronizzazione conserva identità, `kind`, `source`, `proposal`, `terminal`, `chat` e `touched`, non associa Draft e non crea annunci. Non scrive quando il titolo coincide già; un annuncio ritirato o consegnato non viene ricreato. Se la Draft associata non è leggibile o non è più Draft, non modifica il titolo persistito. La sola sincronizzazione non conta come nuova attività: restano le regole vigenti sulle modifiche della Draft, sui quindici minuti di quiete, sulla consegna e sul ritiro.
- The extension owns the fifteen minutes of quiet and the end of the agent's command: it watches the terminals Trama started and the open question round, withdraws the announcements and keeps the notices. It counts the end of a command only when the terminal reports it with the command line Trama typed, compared after trimming; any other end is ignored, as are ends that arrive without a command line. It withdraws only the announcements whose `terminal` is the terminal where the command ended or that was closed. The command line alone never withdraws an announcement on its own.
- The skills `trama-design`, `trama-scan`, `trama-import` and `trama-implement` tell the agent to announce each card as soon as it knows it will create it and to pass the ID when it creates it: `trama-design` for the Proposals it writes after the first, `trama-scan` for each Task and each Drift, `trama-import` for each Proposal and `trama-implement` for the Drift it files and, in the scan of the whole System at the end of a run, for each Task and each Drift. They tell it never to wait for an announcement to be shown before going on. Un sotto-agente annuncia le schede che archivia come l'agente principale.
- La skill `trama-implement` annuncia il controllo finale, ne cambia la fase e lo chiude come dice `rules#announcement`; la skill `trama-scan` annuncia e chiude il controllo della propria scansione, tranne quando la segue dentro una corsa di `trama-implement`, dove usa il controllo della corsa. Entrambe chiudono il controllo prima di scrivere il resoconto, anche quando la verifica fallisce, e non aspettano che il ghost si veda. Un sotto-agente non annuncia controlli.
