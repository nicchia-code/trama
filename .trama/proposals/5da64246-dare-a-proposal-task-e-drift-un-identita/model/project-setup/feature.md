# Project setup

Putting Trama into a project folder and keeping what it installs for the agent up to date: the agent skills that ship with Trama, and one generated skill per Area of Requirements that has content, so that the agent reads the developer's Requirements as skills.

Il developer può, dalla riga di comando, dare un'identità propria alle Proposal, ai Task e ai Drift che hanno ancora un numero. Il comando non entra nell'approvazione, nella scansione né nell'esecuzione dei Task.
