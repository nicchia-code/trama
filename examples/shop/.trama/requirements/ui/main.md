# Interface

## General
- Mobile first; every screen also works at 1280 px wide.
- Amounts show two decimals and the currency symbol.

## checkout
- Every checkout screen shows the cart total at the bottom.

## order/Paid
- A green "Paid" badge next to the order number.
- "Cancel order" is a secondary button; it asks for confirmation first.
