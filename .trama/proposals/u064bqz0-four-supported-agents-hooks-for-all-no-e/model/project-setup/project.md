# Project

A folder that Trama is, or is not yet, set up in: whether it holds a Model, Requirements, Proposals, Tasks and Drifts, and the skills the agent needs.

## States

### Not a Trama project (initial)
The folder has no Trama files. Other actions point the developer to initialize it first.
- `developer.INITIALIZE_PROJECT` → Trama project: creates an empty Model whose description is a placeholder named after the folder, no Actors, the five starting Areas of Requirements (interface, technology, quality, data, business rules), places for Proposals, Tasks and Drifts, and installs the agent skills and the generated Requirement skills. Scrive anche, nella cartella degli agenti di omp del progetto, le definizioni dei due sotto-agenti di omp di Trama (smistamento e analisi). Ogni Area di partenza nasce senza frammenti: il primo lo scrive l'agente. Fails, creating nothing, if Trama files already exist in the folder. If an agent skill file already exists with different content, nothing is created until the developer confirms overwriting them; identical files are not a conflict. Lo stesso vale per una definizione dei sotto-agenti di omp già presente con un contenuto diverso da quello di Trama. In Cursor aggiunge anche le voci di Trama al file degli hook di Cursor del developer (non a quello del progetto), senza toccare le voci che non sono di Trama; in VS Code installa allo stesso modo, a livello utente, il file degli hook di Trama per la chat di Copilot.
- `developer.INITIALIZE_PROJECT` → Not a Trama project: the developer declines to overwrite customised skill files o definizioni personalizzate dei sotto-agenti di omp, cancels choosing among several workspace folders, or no folder is open.

### Trama project
The folder is set up. Its skills may fall behind the version of Trama or the Requirements.
- `developer.UPDATE_SKILLS` → Trama project: writes this version's agent skills, replacing older or edited copies, removes the skill of the Fix action that earlier versions installed (its folder, wherever it is found, whatever its content), creates the five starting Areas if the project has no Requirements folder at all, and regenerates the Requirement skills; reports what changed. Riscrive anche le definizioni dei due sotto-agenti di omp di Trama nella cartella degli agenti di omp del progetto, sostituendo copie vecchie o modificate senza chiedere. Porta al formato a frammenti ogni Area scritta ancora come un file unico: il suo contenuto diventa un solo frammento di quell'Area, che l'agente dividerà la prima volta che una Proposal lo tocca; un'Area che ha già sia il file unico sia i frammenti non viene toccata e il resoconto lo dice. In Cursor riscrive anche le voci di Trama nel file degli hook di Cursor del developer, e in VS Code il file degli hook di Trama per la chat di Copilot, così seguono la posizione del programma di questa versione, e segnala se il file non si può scrivere.
- `workspace.REQUIREMENTS_CHANGED` → Trama project: after a short pause regenerates the Requirement skills, whether or not the Trama panel is open. If that fails the developer is told. Se le skill dei frammenti superano o tornano sotto il budget dell'elenco, le Aree passano tutte insieme da skill per frammento a skill indice, o viceversa.
- `proposal.APPROVED` → Trama project: regenerates the Requirement skills, so the agent sees the Requirements the Proposal changed, passando a skill indice o tornando a skill per frammento allo stesso modo.
- `developer.REWRITE_IDENTITIES` → Trama project: il developer dà un'identità propria a ogni Proposal, Task e Drift ancora numerati. La stessa scheda riceve la stessa identità su ogni copia che parte dallo stesso numero, e un istante di creazione che conserva l'ordine di quei numeri, non l'ora del comando. I riferimenti fra queste schede seguono le identità nuove. Lo stato di ciascuna scheda non cambia e non nasce nessun commit. È rifiutato, senza cambiare nulla, quando due schede dello stesso tipo condividono già un numero, o quando due identità nuove coinciderebbero. Se non c'è nessuna scheda numerata, non cambia nulla.
